How to publish a change
  1. Edit below and click Save draft.
  2. Click Preview draft to see it on the real site (only you can see it).
  3. Click Publish live. Everyone sees the change straight away — no file upload needed (photos too).

Menu prices

Type only the new price (for example 45). Leave a box empty to keep the current price. Changed items turn yellow. You can also type text such as “Market rate”.

Farm products

Type the price for each product (for example 250 shows as ₹250). Leave it empty to hide the price. Tick Unavailable to show the product as “Currently unavailable”. Honey has one price per size.

Photos

Click Change photo and pick a picture from your phone or computer. It is resized and converted to WebP automatically, so the website stays fast. Then Save draft → Preview draft → Publish live. Use original brings the old photo back.
